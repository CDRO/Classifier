USAGE GUIDE

How the review workflow works

Keyboard shortcuts

  • N — move to the next visible document in the inbox
  • D — dismiss the current document and archive it
  • Enter — finalize the current document when a destinee is selected
  • H or ? — open or close this help menu
  • Esc — close the help menu

General flow

  1. Select a file from the inbox to open the review panel.
  2. Review the extracted text, page thumbnails, and suggested filename.
  3. Choose a destinee and confirm the output filename.
  4. Finalize to move the file into the selected output folder and archive the original source.

Useful checks

  • Use the search and folder filters to narrow the queue.
  • Duplicate files are highlighted with a warning before finalization.
  • Use page rotation or split mode when the document needs manual cleanup before routing.
